## 安装与首次显示

1. 退出 KOReader，安装 ZIP 解压得到的 `liuju.koplugin` 文件夹。
2. 如在使用单向历，先关闭它的自动配置屏保。
3. 打开一本有短高亮的 EPUB，等待几秒，进入“工具 → 留句 → 预览一张”。
4. 确认书名、正文和创建日期完整，正常阅读距离下字体清楚。
   默认款正文位于上方。左下角是白色细边的黑色唱片，横跨黑栏边缘。书名与日期在唱片右侧同一行居中。
5. 合盖或按电源键休眠，检查真实锁屏图；唤醒后正常继续阅读。

## 状态与资源

- [ ] 生成过程中立即休眠、唤醒和换书，没有卡死或串书。
- [ ] 关闭书籍进入文件管理器后，最近书籍的屏保保持可用。
- [ ] 快速打开并关闭已有缓存的书，确认仍可随机展示有效小票。
- [ ] 停用留句后切换书籍，确认预览只使用当前书的有效小票。编辑已有笔记后立即预览，确认旧图不再出现。
- [ ] 关闭插件开关后，原屏保设置恢复。
- [ ] 如果设备的休眠屏幕由 Kindle 系统管理，确认留句菜单说明限制，且让出屏保设置。
- [ ] 手动切换其他屏保后，留句让出配置，未反复覆盖。
- [ ] 留句接管后只更改图片拉伸选项，确认原屏保恢复并保留新拉伸选项。
- [ ] 横屏阅读时，睡眠图片与唤醒后的阅读方向正确。
- [ ] 普通阅读和锁屏无需联网。
- [ ] 通过 USB 装入带固定启动入口的版本，在线安装一个更新版本。重启后检查版本号、小票缓存和屏保设置。
- [ ] 用测试包模拟试启动中断和初始化报错，验证重启后恢复上一版本，阅读进度和批注仍可用。
- [ ] 新版在书库启动成功后，模拟首次打开书籍时进程在 ReaderReady 完成前中断，验证再打开 KOReader 会回退。
- [ ] 在新书生成小票前、生成后，以及没有合格标注时点击「预览一张」，确认状态提示与实际显示的图片一致。
