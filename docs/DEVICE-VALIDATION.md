## 安装与首次显示

1. 退出 KOReader，安装候选 ZIP 解压得到的 `liuju.koplugin` 文件夹。
2. 如在使用单向历，先关闭它的自动配置屏保。
3. 打开一本有短高亮的 EPUB，等待几秒，进入“工具 → 留句 → 预览一张”。
4. 确认封面比例、书名、正文、创建日期完整；正常阅读距离下字体清楚。
   正文位于上方。左下角封面黑框与底栏相接，封面上下各露一半。白字书名在右侧空位居中。
5. 合盖或按电源键休眠，检查真实锁屏图；唤醒后正常继续阅读。
