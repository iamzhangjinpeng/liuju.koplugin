# 留句：产品意图

设计日期：2026-11-03  
状态：首版核心功能已实现，桌面版式已选定，待 KPW4 实机视觉验收。

## 1. 希望带来的体验

让读者合上 Kindle 时，自己在当前书里留下的一句话、一段想法，以一张清爽、值得停留几秒的壁纸再次出现。

留句的首要价值是美观。壁纸上的文字需要从容地被读完，封面、字号和留白始终保持稳定；内容通过生成条件筛选，以保证成图质量。

## 2. 使用场景

读者在 KOReader 中打开一本书，像平时一样划线或写批注。留句读取这本书已有的标注，把符合条件的内容生成为图片，并自动接入 KOReader 的睡眠屏保。

每次休眠时，从当前书的小票目录随机选一张图片；选定的图片保持显示，直到下一次休眠。切换书籍后，锁屏图片池随之切换。

## 3. 已确认的首版边界

| 项目 | 规则 |
| --- | --- |
| 运行环境 | 越狱 Kindle 上的 KOReader，首版以竖屏壁纸为视觉目标 |
| 内容来源 | 当前打开书籍中已保存的高亮与批注 |
| 图片池 | 仅使用当前书的小票，换书时自动切换 |
| 壁纸内容 | 书籍封面、书名、摘录或批注、标注创建日期 |
| 元数据 | 壁纸上省去页码和章节 |
| 长度门槛 | 字数上限可设置，默认 80 字；超出上限跳过生成 |
| 排版原则 | 固定字号与版式；正文完整显示；超出可用空间的条目跳过生成 |
| 图片显示 | 从插件专用目录随机选取已经生成的图片 |
| 启用体验 | 插件首次启用即默认开启留句屏保，自动配置目录与显示选项 |

这里的“锁屏”指 KOReader 运行期间的睡眠屏幕。退出 KOReader 后，Kindle 系统的锁屏行为以设备原有机制为准。

## 4. 一条标注怎样成为一张壁纸

首版以一条已保存的标注为单位，最多生成一张图片。

- **只有高亮：**正文展示所划原文。
- **带有批注：**展示原文和自己的笔记，用一个轻量的“笔记”标记区分；两段文字合并计算长度。
- **只有笔记文本：**可以作为批注卡片，展示笔记本身。

内容先经过两道条件：字数不超过设置上限，再按固定字号实际排版，确认能够完整放入正文区域。两道条件均满足才生成图片。

字数规则统一为：中文、字母、数字、标点各计 1 字，空白字符不计数。段落边界保留，过多空行会受到排版空间条件约束。实现时按 Unicode 字符计数。

正文保持标注中的文字与标点。长文不通过截断、摘要、缩小字号或拆成多张的方式进入图片池。

## 5. 壁纸的视觉意图

视觉重心是摘录与笔记。封面承担书籍识别，日期作为安静的落款。

- 使用一套主要版式，根据设备屏幕分辨率等比例排版。
- 参考黑白音乐播放器。正文和日期放在上方，左下角书封带黑框并对半跨过底栏，白字书名在右侧空间居中。
- 正文有足够的字号、行距和周边留白；短文字也保留相同的字号。
- 封面保持比例，书名明确可读，日期使用较低的视觉权重。
- 首版采用适合黑白墨水屏的配色与层次，实际效果以 Kindle 屏幕为准。
- 小票上的装饰保持克制，让封面和文字形成完整画面。
- 图片按设备原生屏幕尺寸生成，屏保显示时隐藏额外的睡眠提示文字。

视觉稿需要同时放入短摘录、接近 80 字的摘录、原文加笔记、长书名和深浅不同的封面进行比较。任何一种内容都不应挤压版式。

## 6. 日期、封面与空内容

日期使用 KOReader 保存的标注创建日期，格式初定为 `YYYY.MM.DD`；编辑笔记后仍保留原始标注日期。记录中没有日期时隐藏日期，避免将生成时间当成摘抄时间。

书籍没有可用封面时，采用统一的书名封面样式。该样式同样需要通过视觉验收。

当前书没有符合条件的小票时，屏保回退到当前书的封面壁纸；无封面时采用统一的书名封面。回退画面与摘录图片池分开保存。文件管理器中沿用最近打开书籍的图片池；尚未打开过书籍时沿用原有屏保。空图片池不能使上一本文字出现在新书的锁屏上。

## 7. 自动更新与操作

打开书籍时，读取当前书的标注并补齐合格图片；新增、编辑或删除标注后，更新对应的小票。换书后，切换到新书的图片池，旧书图片留作该书的本地缓存。

常规阅读中静默处理；批量生成分批进行。实际休眠时直接显示已经完成的图片。

首版设置保持精简：

| 操作 | 用途 |
| --- | --- |
| 启用留句屏保 | 开启时接入壁纸目录，关闭时恢复适用的原屏保设置 |
| 字数上限 | 调整生成门槛，默认 80 字 |
| 更新当前书的小票 | 按当前内容和设置重新检查、生成图片 |
| 预览一张 | 查看当前书中的一张壁纸效果 |

修改字数上限后，以新规则同步当前书的图片池，超出新上限的旧图退出随机展示。

## 8. 成功标准

一张壁纸能让读者在正常阅读距离下轻松读完正文，封面、文字、日期和留白保持协调。接近字数上限的内容也能保持相同的视觉质量。

日常使用时，读者只需要打开书、留下标注、合上 Kindle；图片池与当前书保持一致。重复打开同一本书不会产生重复图片，原始高亮和批注能够完整保留。

## 9. 开发前保留的视觉决策

正文和书名的具体字体、封面位置、小票边缘样式及留白比例，通过一轮原生分辨率样图与 Kindle 实机比较后确定。默认 80 字作为初始门槛，最终默认值随选定版式一起确认。
